# Homelab

A personal homelab project focused on learning modern infrastructure, self-hosting, and DevOps practices.

## Objectives

* Learn Proxmox virtualization
* Self-host personal services
* Deploy game servers
* Learn Docker and containerization
* Automate infrastructure with Python
* Implement CI/CD pipelines
* Learn Infrastructure as Code with Terraform
* Learn Kubernetes

## Hardware
